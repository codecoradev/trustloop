# Contributing

Issues and pull requests are welcome.

- Describe a skill change by the failure it fixes: what you ran, what the skill did, what you expected.
- Run `claude plugin validate . --strict` before opening a pull request, and add or update an eval case in `evals/` when behaviour changes.
- Pull requests target `develop` and use the sections What, Why and Testing.
